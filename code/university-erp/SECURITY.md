# Security policy

## Reporting a vulnerability
Do not open a public issue. Use **Security → Report a vulnerability** (private advisory) on this repository,
or message the Guardian named in THREATMODEL.md. Expect an acknowledgement within two working days.

## Week 8 rules of engagement
Only the team assigned to attack this repository, only on the disposable VM, only during the exercise window.
Every finding is disclosed in writing and reproduced as a failing test before it is fixed.
